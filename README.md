## 💊 What is MedVia?

> **MedVia** is an AI-powered healthcare platform that provides reliable and accurate medicine information instantly.  
> It eliminates the need for a traditional database by generating medicine details dynamically via AI. Users can search medicines and get information about **uses, dosage, and precautions** in a clean, user-friendly interface.

Designed for speed, simplicity, and real-world usability.

---

## 🚀 Features

- 🧠 **AI-Powered Medicine Info**: Generates detailed medicine data on the fly  
- 🔍 **Search Functionality**: Find medicines quickly by name  
- 💊 **Medicine Details**: Purpose, dosage, and precautions  
- 🌐 **Frontend**: Clean HTML/CSS/JS interface  
- ⚡ **Backend API**: ASP.NET Core Web API  
- 💬 **Swagger API Testing** Ready
